02 / IMPLEMENTATION

Python Source Code

Calculate PageRank scores and visualize the top 30 nodes.

facebook_PRA.py 
import matplotlib.pyplot as plt
import networkx as nx

# Load the Facebook social network dataset
G = nx.read_edgelist(
    "facebook_combined.txt.gz",
    nodetype=int
)

# Calculate PageRank scores
fb = dict(nx.pagerank(G))

print("\n|| Page-Rank Of each Node in Facebook ||")
print("========================================")

for node, rank in fb.items():
    print(f"Node({node})-> {rank}")

print("========================================\n")

# Find the node with the highest PageRank
max_node, max_pr = max(
    fb.items(),
    key=lambda x: x[1]
)

print("Maximum PageRank Value and its node:")
print(f"Node({max_node}): {max_pr}")
print("========================================\n")

# Select the top 30 nodes
top_nodes = sorted(
    fb,
    key=fb.get,
    reverse=True
)[:30]

# Create a subgraph containing the selected nodes
H = G.subgraph(top_nodes)

# Calculate positions for visualization
pos = nx.spring_layout(
    H,
    seed=42,
    iterations=50,
    k=5
)

# Draw the graph
nx.draw_networkx(
    H,
    pos=pos,
    node_size=1200,
    node_color="green",
    font_color="white",
    font_size=10,
    edge_color="red",
    font_weight="bold",
    with_labels=True,
    width=2
)

plt.title("TOP 30 FACEBOOK NODES BY PAGERANK")

plt.figtext(
    0.5,
    0.02,
    f"Node({max_node}): {max_pr} [Maximum PageRank Value]",
    ha="center",
    fontsize=12,
    fontweight="bold",
    color="blue"
)

plt.show()

Run the program

Save the Python code as facebook_PRA.py and run:

Terminal 
python facebook_PRA.py
03 / EXPLANATION

How the Program Works

01

Import libraries

NetworkX handles graph operations and PageRank calculations. Matplotlib displays the graph.

02

Load the dataset

nx.read_edgelist() reads connections between Facebook nodes from the dataset file.

03

Calculate PageRank

nx.pagerank(G) calculates a score for each node based on the graph's link structure.

04

Find the highest score

The max() function identifies the node with the largest PageRank score.

05

Visualize the top 30 nodes

The program selects the 30 highest-ranked nodes and draws the subgraph containing those nodes.

Important: The graph displays edges that already exist between the selected top 30 nodes. It does not automatically create connections between every selected node.
