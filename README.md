# 📊 PageRank Algorithm

A simple educational website about the **PageRank (PR) Algorithm**, built using **Python and Flask**.

This is my **first Flask-based web application**. I created this project to understand how a Flask web application actually works and to share basic knowledge about the **PageRank Algorithm**.

The project is created **only for learning and educational purposes**.

## ✨ Features

- 📖 Introduction to PageRank
- 🔗 Explanation of links between web pages
- ⭐ Understanding link quality
- 🔄 Basic explanation of how PageRank works
- 🌐 Simple responsive web interface
- 📄 Home, About, and Contact Us pages
- 🐍 Built using Flask

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## 🚀 How to Run

### 1. Install Flask

```bash
pip install flask
```

### 2. Run the application
```bash
python backend.py 
```
