What is PageRank?

PageRank is an algorithm used to estimate the importance of a web page. It looks at the links between differentpages. A page can receive importance from other pages that link to it. The basic idea is that a page linked by many useful and important pages may also be considered important.

Web Pages as a Graph:

To understand PageRank, we can think of the web as a graph.
In a graph:
Node → represents a web page.
Edge → represents a link between two web pages.
Direction → shows which page is linking to which page.

For example, if Page A links to Page B:
A → B
Here, A and B are nodes, and the arrow from A to B is an edge.

Links Can Be Like Votes:

If Page A links to Page B, Page A is giving some importance to Page B.
A link can be thought of as a vote or recommendation.
For example:
A ──> C
B ──> C
D ──> C

Here, three pages are linking to C. This can be a sign that C is important. However, PageRank does not simply count the number of links.

Not All Votes Have the Same Value:

A link from an important page can be more valuable than a link from a less important page.
For example:
Important Page ──> C
Less Important Page ──> C

The link from the important page may contribute more PageRank to C. This is one of the main ideas behind PageRank.

Number of Outgoing Links Matters:

Suppose Page A links to two pages:-
┌──> B
A ───┤
└──> C

A's PageRank is divided between B and C. If A links to many pages, its PageRank is distributed among more pages. This is why PageRank considers not only who links to a page, but also how many outgoing links the linking page has.

PageRank Uses Repeated Calculations:

PageRank is not normally calculated just once.
The algorithm starts with initial values and repeatedly updates them.
The general process is:

  • Give every page an initial PageRank.
  • Look at the links between pages.
  • Pass PageRank through those links.
  • Calculate new PageRank values.
  • Repeat the process.
  • Continue until the values become stable.

This repeated process allows the importance of one page to affect the importance of other pages.

Damping Factor:

PageRank also uses a concept called the damping factor.
The damping factor represents the idea that a person browsing the web may sometimes follow a link and sometimes jump to another page directly.
Damping Factor denoted as 'd' and value of d is:
d = 0.85

PageRank Formula:

The basic PageRank formula can be written as:
-----------------------------------------------------------
PR(A) = (1 - d) / N + d × Σ(PR(B) / L(B))
-----------------------------------------------------------

Where:

  • PR(A) → PageRank of page A
  • d → damping factor
  • N → total number of pages
  • PR(B) → PageRank of a page linking to A
  • L(B) → number of outgoing links from page B
